## 3. Exact query text

The file `TQL_AND_NATIVE_2026-11-22_15-04-04.txt` holds the TQL shapes and their native SQL or q equivalents. The file `SQL_CORPUS_2026-11-22_15-04-04.sql` holds the 24 SQL statements from the complete execution plan.

The IMDb Q1 SQL text is the native query for TQL case 1:

`SELECT COUNT(*), AVG(r.averagerating), SUM(r.numvotes) FROM title_basics b JOIN title_ratings r ON r.tconst=b.tconst WHERE b.titletype='movie' AND b.startyear>=2000 AND r.averagerating>=7.5`

The IMDb Q2 Cypher text is the native query for TQL case 2:

`MATCH (p:Person)<-[:PRINCIPAL]-(t:Title) WITH p, count(t) AS d WHERE d > 1 RETURN sum(d*(d-1)) AS pairs`

The IMDb Q3 text is a description only. The document names it "4-table decade rollup". It gives no exact query text.
