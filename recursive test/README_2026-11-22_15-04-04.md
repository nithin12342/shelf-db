## 1. Goal

This folder consolidates benchmark datasets and benchmark query text from the approved documents. It does not add a new benchmark. It does not run a benchmark. It uses only the restored database documents and the active instruction files. The protected neural-network archive stays excluded.

## 2. File index

Table 1 answers this question: which files hold each part of the consolidation. Rows are files. Columns are the file name and the content.

| File | Content |

## 3. Rules used

1. I record exact query text when a document gives exact query text.
2. I record a workload name when a document gives only a workload name.
3. I mark a data set as proposed when a document proposes it but does not measure it.
4. I cite the source document for every row.
