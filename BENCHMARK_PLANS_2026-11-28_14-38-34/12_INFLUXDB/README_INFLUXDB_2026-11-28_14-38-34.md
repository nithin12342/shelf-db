## 1. Goal

This folder holds the two InfluxDB pair plans. Each plan compares InfluxDB with ShelfDB on one Time Series Benchmark Suite (TSBS) use case. This folder holds plans only. It does not run a benchmark.

## 3. Common facts

1. The original benchmark link is `https://github.com/timescale/tsbs`.
2. The container image is `influxdb:2`. The default endpoint is `http://localhost:8086`.
3. The InfluxDB supplement gives command names and flags. It does not give a full loader command line.
4. The suite uses one container, one central processing unit, 2 GB memory, and one thread.
5. The target subset is 100,000 rows. Do not extract the full 5.22 GB bundle.
6. ShelfDB runs as a native process through `sheaf_db_app.exe` with a `--data-file` flag.
7. The TSBS sources give query type names. They do not give generated query text. Do not invent query text.
