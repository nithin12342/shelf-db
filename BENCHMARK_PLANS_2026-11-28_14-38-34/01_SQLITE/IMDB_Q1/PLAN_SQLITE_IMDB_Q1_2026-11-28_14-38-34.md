## 1. Goal

This plan compares SQLite with ShelfDB on IMDb Q1. IMDb Q1 filters movies from year 2000, filters ratings at 7.5 and above, then counts rows, sums votes, and averages the rating. The plan names the source, the data, the cases, the commands, and the gate. The plan does not run the benchmark.

**TQL:** Topological Query Language, a declarative query over a cellular complex.
**SQL:** Structured Query Language, the standard language for relational databases.

## 5. Query text

The approved documents give exact text for Q1. Use that text. Do not change the predicates.

### 5.1 Exact native SQL

The source is `recursive test/TQL_AND_NATIVE_2026-11-22_15-04-04.txt`, case 1, native SQL. The same text appears in `TQL_APPLICATION_COMPARISON_2026-10-26.md`, Table 1.

```sql
SELECT COUNT(*), AVG(r.averagerating), SUM(r.numvotes) FROM title_basics b JOIN title_ratings r ON r.tconst=b.tconst WHERE b.titletype='movie' AND b.startyear>=2000 AND r.averagerating>=7.5
```

### 5.2 Exact TQL shape

The source is the same file, case 1, TQL. The optimizer does not execute this shape. The execution bridge is a plan.

```text
MATCH HYPERCELL c: Casting OVER (t: Title, p: Person) WHERE t.year > 2000 AND t.rating > 75 SOLVE HARMONIC (REGULARIZATION: 0.01, MAX_ITERATIONS: 25, ENERGY_THRESHOLD: 0.005) EMIT SECTION { p.name, t.rating, SECTION_ENERGY };
```
