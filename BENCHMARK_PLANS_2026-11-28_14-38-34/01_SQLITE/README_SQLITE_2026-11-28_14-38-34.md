## 1. Goal

This folder holds the SQLite versus ShelfDB benchmark plans. Each plan names its data set, its cases, its commands, and its gate. The plans use the benchmark cases that the approved documents name. The plans do not add a new benchmark.

## 2. Concept definitions

- **TQL:** Topological Query Language, a declarative query over a cellular complex.
- **SQL:** Structured Query Language, the standard language for relational databases.
- **SQLite:** an embedded relational database that runs in the client process.
- **ShelfDB:** the sheaf database that stores answer sections in a fiber bundle.
- **Gate:** an automatic comparison of a result with a stated truth value.

## 5. Shared rules

1. Read one plan before you run one command.
2. Make sure that the named data subset exists in the local bundle.
3. Use the exact query text that the plan quotes.
4. Do not invent SQL text. If a source gives a workload name only, record the name only.
5. Run one warm-up pass. Do not time the warm-up pass.
6. Run three measured passes with one thread.
7. Record the command, the output, the load time, the query time, and the result checksum.
8. Compare the checksum with the truth value that the plan names.
9. Write `unsupported` with the file name when a source file is absent. Do not substitute an invented query.
10. Stop the container before you start the next plan.
