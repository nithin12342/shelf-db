## 1. Result

This folder holds five plan files. Each plan compares Neo4j with ShelfDB on one benchmark pair. This folder does not run a benchmark. This folder does not pull an image.

## 2. Terms

- **Neo4j:** a property graph database that stores nodes, relationships, and properties.
- **Cypher:** the query language for Neo4j.
- **Topological Query Language (TQL):** a declarative query over a cellular complex.
- **ShelfDB:** the database under test. It stores answers in sectioned fiber bundles.
- **Pair:** one benchmark case that runs on Neo4j and on ShelfDB.
- **Gate:** a condition that a real result must meet.

## 4. Low-power limits

Table 2 answers this question: which limits govern every plan in this folder. Rows are limits. Columns are the limit, the allowed value, and the reason.

| Limit | Allowed value | Reason |

## 6. Command shapes

Use this shape for each Neo4j container. The limit flags come from `BENCHMARK_EXECUTION_PLAN_2026-11-28_14-19-54.md`.

```text
docker run --rm --name bench-neo4j --cpus=1 --memory=2g \
  --pids-limit=128 -p 7474:7474 -p 7687:7687 neo4j:5-community
```

Use this shape for each ShelfDB measurement.

```text
cargo run -p sheaf-engine --bin <named-binary> --release
```

The named binary comes from the plan file. Do not guess a binary name.

## 7. Evidence layout

The summary must name the remote, the branch, the base commit, the data set, the benchmark tool, the image digest, and the gate result.

## 8. Acceptance gate

1. Run one container at a time.
2. Use one central processing unit, two gigabyte of memory, and one thread.
3. Make sure that the loaded row count matches the subset manifest.
4. Make sure that the result checksum matches the stated expected result.
5. Keep the evidence folder with commands, outputs, and checksums.
6. Stop the container and remove its volume after the pair.
7. Report `unsupported` when a required tool or data set is absent. Do not report a fake result.

## Warnings

- **WARNING:** Do not run Docker, a release build, and a benchmark suite at the same time. The laptop can stall.
- **CAUTION:** LDBC updates persist. Restore the database before each LDBC run.
- **CAUTION:** The 50-case document gives names, not SQL text. Do not invent query text.
- **NOTE:** These are plans only. No image was pulled and no benchmark ran.
