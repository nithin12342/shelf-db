## 1. Goal

## 5. How to use the plans

1. Read one plan.
2. Make sure that the named data subset exists in the bundle.
3. Pull one image.
4. Load the named subset.
5. Run the original benchmark command from the plan.
6. Run the matching ShelfDB command from the same plan.
7. Compare row counts and checksums.
8. Write the evidence files with the run timestamp.
9. Stop the container and wait three minutes before the next pair.

## Warnings

- **CAUTION:** The host is a low-power laptop. Run one database at a time.
- **CAUTION:** The 50 fraud cases give names only. Do not invent SQL for them.
- **CAUTION:** BenchBase has no DuckDB profile and the documents name no ShelfDB adapter. That plan sets an `unsupported` gate.
- **NOTE:** DuckDB has no server image. The plans use a language image and install the embedded library.
- **NOTE:** These are plans only. No image was pulled and no benchmark was run.
