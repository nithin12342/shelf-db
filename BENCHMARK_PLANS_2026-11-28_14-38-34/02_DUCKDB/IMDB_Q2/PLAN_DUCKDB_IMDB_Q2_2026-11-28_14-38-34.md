## 1. Goal

This plan pairs DuckDB with ShelfDB on IMDb query 2 (Q2), a four-table top-ten join. DuckDB runs the recorded Structured Query Language (SQL) text. ShelfDB runs the recorded top-ten answer path. This plan does not install software and does not run a benchmark.

## 2. Concept definitions

- **DuckDB:** an embedded columnar database that runs SQL in one process.
- **ShelfDB:** a sheaf database that stores answers in binary cellular storage sections.
- **Answer section:** a stored record that a query reads after the bundle build.
- **SQL:** the standard language for relational queries.
- **Gate:** an automatic comparison of an engine result with a truth value.

## 6. Exact query text

The SQL text is exact. It comes from `sheaf-db/tests/e2e/realtime_bench/imdb_complex_bench.py`, lines 42 to 47.

```sql
SELECT n.primaryname, COUNT(*) AS c FROM title_principals p
         JOIN title_basics b ON b.tconst = p.tconst
         JOIN title_ratings r ON r.tconst = p.tconst
         JOIN name_basics n ON n.nconst = p.nconst
         WHERE p.category IN ('actor','actress') AND n.birthyear>=1970 AND r.averagerating>=8.0
         GROUP BY n.primaryname ORDER BY c DESC, n.primaryname ASC LIMIT 10
```

Run the same text in both engines. Compare the MD5 result hash. Report the computed time and the stored-answer time in separate rows.
