## 1. Goal

This plan pairs DuckDB with ShelfDB on IMDb query 3 (Q3), a four-table decade rollup. DuckDB runs the recorded dialect-neutral Structured Query Language (SQL) text. ShelfDB runs the recorded decade answer path. This plan does not install software and does not run a benchmark.

## 2. Concept definitions

- **DuckDB:** an embedded columnar database that runs SQL in one process.
- **ShelfDB:** a sheaf database that stores answers in binary cellular storage sections.
- **Dialect divergence:** a case where two SQL engines return different values for the same text.
- **SQL:** the standard language for relational queries.
- **Gate:** an automatic comparison of an engine result with a truth value.

## 6. Exact query text

The SQL text is exact. It comes from `sheaf-db/tests/e2e/realtime_bench/imdb_complex_bench.py`, lines 56 to 61. The FLOOR form removes a recorded dialect divergence.

```sql
SELECT CAST(FLOOR(b.startyear / 10.0) AS INTEGER) * 10 AS decade, COUNT(*), AVG(r.averagerating) FROM title_basics b
         JOIN title_ratings r ON r.tconst = b.tconst
         JOIN title_principals p ON p.tconst = b.tconst
         JOIN name_basics n ON n.nconst = p.nconst
         WHERE b.genres LIKE '%Drama%' AND r.numvotes>10000 AND b.startyear>=1950
         GROUP BY decade HAVING COUNT(*)>500 ORDER BY decade
```

Plain division and a plain cast gave 59 decades in DuckDB and 8 decades in PostgreSQL. The recorded gate requires 8 decades. Use the text above in both engines.
