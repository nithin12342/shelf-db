## 1. Goal

This index names every MariaDB versus ShelfDB pair plan. Each pair has one folder and one plan file. The plans use the original benchmark cases from the linked tools. The plans do not install software, pull an image, load data, or run a benchmark.

A TQL statement is a declarative query over a cellular complex. SQL is the standard query language for relational databases. MariaDB is a row-store relational database. A gate is an automatic test that compares a result with a truth value.

## 7. How the plans will be used

1. Read one pair plan.
2. Make sure that the named data subset exists in the bundle.
3. Pull one container image and record its digest.
4. Load the named subset and record the row count.
5. Run the exact original benchmark command from the plan.
6. Run the matching ShelfDB command from the same plan.
7. If the plan records `unsupported`, write the error with the named cause.
8. Compare row counts and checksums.
9. Record timings with the data set name and the benchmark tool name.
10. Stop the container before the next pair.
