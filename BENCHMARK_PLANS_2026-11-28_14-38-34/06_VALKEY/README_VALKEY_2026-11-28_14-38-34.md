## 1. Goal

This folder holds two benchmark pair plans for Valkey. A pair is one original benchmark and one matching ShelfDB command. A plan states sources, data, commands, limits, evidence, and a gate. A plan does not install software. A plan does not run a benchmark.

Topological Query Language (TQL) is a declarative query over a cellular complex.

## 3. Rules used

1. Record exact query text or an exact command when a source gives one.
2. Record a name only when a source gives a name only. Do not invent text.
3. Use one database container at a time. Use one central processing unit (CPU). Use 2 gigabytes (GB) of memory. Use one benchmark thread.
4. Use one subfolder and one plan file for each pair.
5. State `unsupported` when no matching ShelfDB command exists. Do not make up a result.
6. Do not copy a Redis timing into a Valkey result. The approved documents hold no measured Valkey number.
