## 1. Goal and terms

This plan pairs ScyllaDB with ShelfDB on a range slice of 10,000 rows. A range slice reads a contiguous set of rows by key order. Cassandra Query Language (CQL) is the query language of ScyllaDB. Topological Query Language (TQL) is the declarative query language of ShelfDB over a cellular complex.

The source records two range shapes. One reads the `bench.kv` table. The other reads the denormalized `imdb.by_year` table. This plan names both and keeps their results in separate rows.

## 5. Exact query text

The source files give exact CQL. Use them without change.

KV range slice from `sheaf-db/tests/e2e/realtime_bench/scylla_bench.py`:

```sql
SELECT id FROM kv WHERE rng=7
```

IMDb by-year range slice from `sheaf-db/tests/e2e/realtime_bench/imdb_multi_engine_bench.py`:

```sql
SELECT tconst, avg, votes FROM imdb.by_year WHERE year=2000 AND tconst > 'tt0000' LIMIT 10000
```

Table definition for the IMDb case:

```sql
CREATE TABLE imdb.by_year (year int, tconst text, avg double, votes int, PRIMARY KEY (year, tconst))
```

## 9. Matching ShelfDB command

```text
cargo run --release --bin range_slice_bench
```

The binary builds a name index over 500,000 cells and times five slice passes. It prints a full-scan baseline, a relative error, a row count, a best time, and a median time. Use the printed values as the gate. Do not time the index build unless the result column names total time.
