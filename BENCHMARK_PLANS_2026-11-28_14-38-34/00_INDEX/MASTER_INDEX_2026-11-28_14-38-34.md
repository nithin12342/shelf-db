## 1. Goal

This index names every database that the approved documents compare with ShelfDB. Each database gets its own folder. Each database, data set, and benchmark pair gets its own plan file. The plans use the original benchmark cases from the linked benchmark tools. The plans do not install software or run benchmarks.

Topological Query Language (TQL) is a declarative query over a cellular complex. Structured Query Language (SQL) is the standard query language for relational databases.

## 5. Databases that stay outside this comparison

The bundled tools list more backends. The approved documents do not name them as opponents for ShelfDB. Do not write comparison plans for them: Akumuli, Cassandra, CrateDB, SiriDB, Timestream, VictoriaMetrics, CockroachDB, Spanner emulator, TigerGraph, GraphDB, and Umbra. Record them as tool-supported but not selected.

## 6. How the plans will be used

1. Read one database plan.
2. Make sure that the named data set exists in the bundle.
3. Pull one container image.
4. Load the named subset.
5. Run the exact original benchmark command from the plan.
6. Run the matching ShelfDB command from the same plan.
7. Compare row counts and checksums.
8. Record timings with the data set name and the benchmark tool name.
9. Stop the container before the next plan.
