## 1. Goal

This folder holds the two QuestDB pair plans. Each plan compares QuestDB with ShelfDB on one Time Series Benchmark Suite (TSBS) use case. This folder holds plans only. It does not run a benchmark.

## 3. Common facts

1. The original benchmark link is `https://github.com/timescale/tsbs`.
2. The container image is `questdb/questdb:latest`.
3. The QuestDB supplement uses an InfluxDB line protocol port and a REST endpoint.
4. The QuestDB supplement marks its tool install example as a FreeBSD example.
5. The suite uses one container, one central processing unit, 2 GB memory, and one thread.
6. The target subset is 100,000 rows. Do not extract the full 5.22 GB bundle.
7. ShelfDB runs as a native process through `sheaf_db_app.exe` with a `--data-file` flag.
8. The TSBS sources give query type names. They do not give generated query text. Do not invent query text.
